hive:

(start the docker desktop)

1 : docker pull apache/hive:4.2.1

2 : docker run -d -p 10000:10000 -p 10002:10002 --env SERVICE_NAME=hiveserver2 --name hiveserver2 apache/hive:4.2.1

3 : docker start hiveserver2

4 : docker exec -it hiveserver2 beeline -u "jdbc:hive2://localhost:10000/"

 

You get : 0: jdbc:hive2://localhost:10000/>
